# Remote and Cloud Sessions


These variables matter when Claude Code runs away from your terminal.
They cover cloud sessions, the remote bridge, the desktop app, the Chrome extension, Cowork, and Slack.
Most are set by the host, and Claude Code reads them. Set one yourself only when you run your own host.

## At a Glance

| Question | Answer |
| --- | --- |
| Can you use it? | Partly. Many are set by the host program that starts Claude Code. |
| Can you change it? | ✅ Yes, if you control the process that starts Claude Code. |
| Can you turn it on or off? | Unset the variable. |
| Where does it live? | The environment of the Claude Code process. |
| Rows on this page | 137 variables |
| Status | [Documented] [Undocumented] [Differs] [Gated] |

## Example

```bash
CLAUDE_CODE_REMOTE=true claude -p "Summarize the repo"
```

`CLAUDE_CODE_REMOTE=true` marks the run as a cloud session. Claude Code then raises its Node heap limit to 8192 MB.

## How It Works

A host program starts Claude Code as a child process and passes variables to it.
The child reads them to learn where it runs and how to reach the host.
Check the Notes column: some variables are set by Claude Code itself and are not meant to be set by you.
